# 📊 Customer Behavior Dashboard

An interactive **Customer Behavior Dashboard** built using **Python, SQL, and Power BI** to analyze customer purchasing patterns, sales performance, and customer segmentation.

---

## 🚀 Project Overview

The **Customer Behavior Dashboard** provides meaningful insights into customer purchasing behavior and helps businesses understand their customers better.

The project includes data cleaning and analysis using **Python and SQL**, followed by interactive visualization and reporting in **Power BI**.

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior
- Identify high-value and repeat customers
- Analyze sales and revenue trends
- Understand customer demographics
- Identify popular product categories
- Analyze customer segments
- Create an interactive business dashboard
- Generate actionable business insights
